# Сайт «Адвокат» — первая серверная версия

## Возможности
- Адаптивный сайт на русском языке.
- Список свободных временных слотов из базы данных.
- Серверная валидация заявок.
- SQLite хранит заявки; уникальное ограничение на дату и время предотвращает двойное бронирование.
- Простая панель администратора: `/admin`.
- Статусы заявки: new, confirmed, cancelled.

## Запуск локально
Требуется Node.js 20+.

```bash
npm install
```

Задайте сильный пароль администратора в переменной окружения `ADMIN_PASSWORD`.

macOS/Linux:
```bash
ADMIN_PASSWORD='replace-with-a-long-random-password' npm start
```

PowerShell:
```powershell
$env:ADMIN_PASSWORD='replace-with-a-long-random-password'; npm start
```

Откройте `http://localhost:3000`, панель администратора — `http://localhost:3000/admin`.

## Перед реальным запуском
1. Настроить HTTPS и безопасное хранение секретов на хостинге.
2. Убедиться, что SQLite-файл хранится на постоянном диске; некоторые бесплатные хостинги стирают локальные файлы при перезапуске. Для такого хостинга нужна внешняя база данных или persistent disk.
3. Заменить заглушки контактов на подтверждённые сведения.
4. Привести политику и согласие в соответствие с реальной обработкой данных и актуальными требованиями 152-ФЗ; проверить локализацию хранения персональных данных и другие применимые требования.
5. Добавить уведомления адвокату (например, через почту или Telegram) после настройки и защиты соответствующих секретов.
6. Рассмотреть более надёжную авторизацию администратора, ограничение попыток входа, резервное копирование, журналирование и защиту от спама.
7. Определить фактические часы приёма, выходные и правила подтверждения записи. Сейчас слоты заданы демонстрационно в коде.

## Важно
Это стартовый проект, а не юридическая или security-аудированная система. Не размещайте публично до проверки конфигурации, защиты персональных данных и тестирования резервного копирования.
